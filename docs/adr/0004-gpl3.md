# ADR 0004 — GPL-3.0-or-later

- Status: accepted
- Date: 2026-10-23

## Context

Folderol is a desktop application, not a library. It links GTK (LGPL-2.1+) and
SQLite (public domain). The license should keep the project and its
improvements open, match the norms of Linux desktop file managers, and remain
compatible with the dependencies.

## Decision

GPL-3.0-or-later. The full text lives in `LICENSE`.

## Alternatives considered

- **MIT / Apache-2.0 dual.** Maximum reuse, including in closed products.
  Rejected because a file manager with a personal model is a long-lived
  application where copyleft protects user freedom and shared improvements.
- **MIT.** Simplest, but weaker for an application.
- **AGPL-3.0.** Adds network-use obligations that a local desktop tool does not
  need. It also complicates adoption without changing the practical outcome.
- **MPL-2.0.** File-level copyleft is a reasonable middle ground, but the
  ecosystem expectation for GNOME-adjacent apps is GPL.

## Consequences

- Forks and redistributions must remain GPL-3.0-or-later and provide source.
- The license is compatible with GTK (LGPL) and SQLite (public domain).
- Any future code copied from an MIT/Apache project remains compatible; the
  reverse (taking GPL code into a permissive project) would not be, which is the
  intended direction.
- Contributors license their work under the same terms; no CLA is required.
- Model weights distributed with the app must have compatible licenses. A
  permissively licensed embedding model is a selection criterion, recorded in
  the model manifest.
